# Privacy Policy — moved

The canonical privacy policy now lives at [`PRIVACY.md`](../PRIVACY.md) in
the repository root.

This file is kept only so existing links keep resolving. Its previous
contents (audited 2026-06-11) described the daemon's outbound connections as
the content host, the configured AI backend, and PyPI for yt-dlp updates —
which is no longer complete. Follow-up questions can run a DuckDuckGo search
and fetch the pages it returns (disableable via `qa.web_search`), and a
diagnostics report can be built on request. Both are documented in
`PRIVACY.md`, along with the local-versus-cloud distinction.

A privacy policy that understates what leaves the machine is worse than no
policy at all, so the stale text was replaced rather than left in place.

For the Chrome Web Store dashboard wording (permission justifications,
data-use disclosure, reviewer instructions) see
[`store-listing.md`](store-listing.md); for the permission audit and the
minimizations it applied, see
[`permissions-justification.md`](permissions-justification.md).
